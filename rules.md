#Cursed Calc Rules:
main goal:
Make a working integer-based console calculator while following the additional restrictions of current difficulty.

-following operations must be implemented:
add (a+b)     - int
sub (a-b)     - int
mul (a*b)     - int
div (a/b)     - int
mod (a mod b) - int

##General rules
-int overflow may be ignored unless stated otherwise
-division by zero must be handled correctly

-no libm
-no asm
-a previously implemented function may be called on later difficulties only if its implementation is valid under the current difficulty
-no turning integers to strings/chars
-no lookup tables w/ precomputed results
-no external programs for calculation
-casts cannot be used to bypass dificulty
-difficulty restrictions apply to the entire calculation core
-non-calculation syntax is exempt from difficulty restrictions
-all restrictions are cumulative unless explicitly overriden

No loopholes.
If something technically follows the syntax but obviously performs a forbidden operation indirectly, it violates the spirit of the challenge.
